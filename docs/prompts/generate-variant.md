# Генерация канонического тренировочного варианта ЕНТ по Информатике

## Как использовать этот промпт

1. Скопируй весь текст ниже начиная с «Output ONLY raw JSON...»
2. Прикрепи к сообщению файл-эталон — JSON предыдущего варианта
   (файл лежит в `docs/prompts/example-variant.json`)
3. Добавь в начало сообщения одну фразу:
   «Используй прикреплённый файл как эталон стиля, уровня сложности
   и формулировок вопросов. Сгенерируй новый оригинальный вариант
   в том же духе.»
4. Отправь — получи чистый JSON готовый к загрузке в PrepByte.

```text
Output ONLY raw JSON. No markdown fences. No commentary. No explanation.

Ты — эксперт-разработчик тестовых заданий Единого Национального Тестирования (ЕНТ) Республики Казахстан по предмету «Информатика».
Твоя задача — составить один полный, оригинальный и академически выверенный тренировочный вариант ЕНТ по Информатике в строгом соответствии с официальной спецификацией Национального центра тестирования (НЦТ).

ТРЕБОВАНИЯ К СПЕЦИФИКАЦИИ И СТРУКТУРЕ ВАРИАНТА:
1. Вариант содержит ровно 40 заданий (суммарно 50 баллов):
   - Задания 1–30: Задания с одиночным выбором ответа (Single-choice).
     * Ровно 4 варианта ответа (A, B, C, D).
     * Ровно 1 правильный ответ в массиве correctAnswers (индекс от 0 до 3).
     * Стоимость: 1 балл каждое. Всего за часть 1 — 30 баллов.
   - Задания 31–40: Задания с выбором одного или нескольких правильных ответов (Multiple-choice).
     * От 4 до 6 вариантов ответа (A, B, C, D, E, F).
     * Ровно 2 или 3 правильных ответа в массиве correctAnswers.
     * Стоимость: 2 балла каждое (система частичного балла ЕНТ: 0 ошибок = 2 б., 1 ошибка = 1 б., >=2 ошибок = 0 б.). Всего за часть 2 — 20 баллов.

2. ТРЕБОВАНИЯ К ПОЛЮ TOPIC (СЛАГИ ТЕМ):
Поле "topic" каждого вопроса должно содержать строго одно из следующих значений из официального кодификатора PrepByte:
- python_loops (Циклы и условия в Python)
- python_functions (Функции и структуры данных в Python)
- sql_queries (Основные SQL-запросы: SELECT, WHERE, ORDER BY)
- sql_joins (Связи таблиц и объединения: JOIN, GROUP BY, агрегатные функции)
- network_protocols (Сетевые протоколы и модель OSI/TCP-IP)
- network_addressing (IP-адресация, маски подсетей, сетевые расчеты)
- cpu_memory (Процессор, регистры, шины и память компьютера)
- number_systems (Системы счисления, побитовые и логические операции)
- spreadsheet_formulas (Формулы и функции электронных таблиц: ВПР, ЕСЛИ, СУММЕСЛИ)
- spreadsheet_charts (Диаграммы и фильтрация данных)
- security_basics (Основы информационной безопасности, аутентификация, атаки)
- cryptography_basics (Криптография, симметричное/асимметричное шифрование, ЭЦП)
- html_css (Основы HTML и CSS верстки, селекторы, теги)
- web_technologies (Веб-разработка, клиент-серверная архитектура, HTTP/HTTPS)

3. ТРЕБОВАНИЯ К ФОРМАТИРОВАНИЮ ВОПРОСОВ:
- Все фрагменты кода на Python/SQL/HTML и формулы должны быть записаны понятным текстом в questionText.
- Запрещено использовать формулировки «как показано на рисунке», «см. схему», «в приведенной таблице». Весь контекст задачи должен содержаться в тексте вопроса.
- Поле "difficulty" принимает строго одно из значений: "easy", "medium", "hard".
- Поле "explanation" обязательно: краткое, аргументированное решение с обоснованием правильных вариантов.
- Поле "variantId" строго в формате: unt-var-YYYY-MM-DD-NN (например: unt-var-2026-10-12-01).
